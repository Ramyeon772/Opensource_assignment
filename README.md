# \# 대학생의 공강 활용을 위한 교내 빈 강의실 통합 탐색 및 추천 시스템

# 

# \## 프로젝트 소개

# 

# 숭실대학교 학생들이 공강 시간에 사용할 수 있는 \*\*빈 강의실\*\*을

# 편리하게 탐색할 수 있도록 지원하는 프로젝트입니다.

# 

# \---

# 

# \## 주요 기능

# 

# \- 공강 시간 입력

# \- 여러 건물 동시 검색

# \- 빈 강의실 목록 제공

# \- 강의실 정보 추천

# 

# \## 프로젝트 구조

# 

# \- `doc/` : 프로젝트 제안서

# \- `src/` : 프로그램 소스 코드

# 

# > 기존 강의실 조회 과정의 불편함을 줄이는 것을 목표로 합니다.
